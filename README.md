# MangaLibDownoloader

Многопоточный загрузчик манги с сайта MangaLib, который обходит защиту Cloudflare благодаря использованию реального Chromium-браузера (через `DrissionPage`). Программа собирает список глав, позволяет выбрать нужный диапазон для скачивания и быстро выкачивает страницы с удобным отображением прогресса и ETA.

## Особенности
* **Обход Cloudflare (Rate Limits 429)**: Имитация настоящего браузера и передача `cookies` в `requests.Session` для беспрепятственного скачивания.
* **Многопоточность загрузки**: Ссылки глав собираются последовательно с паузами, чтобы не упираться в лимит MangaLib, а сами изображения скачиваются отдельным пулом потоков.
* **Гибкий выбор глав**: Можно скачивать как одну главу, так и целый диапазон (например `0-10`, `0,1,5`).
* **Удобный интерфейс**: Красивые индикаторы прогресса (Progress bars) на базе библиотеки `rich`.
* **Авто-повтор**: Для главы, страницы которой не удалось получить, выполняется до трёх попыток с увеличивающейся паузой.
* **PDF или CBZ по томам**: После загрузки можно собрать отдельный PDF или CBZ для каждого затронутого тома либо оставить только изображения. В сборку входят все уже скачанные главы тома, даже если загрузка началась не с первой главы.
* **Kindle Comic Converter**: Можно оптимизировать тома под Kindle, Kobo, reMarkable и другие устройства через KCC. Недавние профили показываются первыми, но устройство всё равно выбирается при каждом запуске.

## Требования
* Python 3.8+
* Google Chrome (для работы `DrissionPage`)
* Git (нужен `pip` для установки KCC из официального репозитория)

## Установка

1. Склонируйте репозиторий или скачайте файлы в любую папку.
2. Установите необходимые библиотеки с помощью команды:
```bash
pip install -r requirements.txt
```

## Использование

Запустите главный скрипт:
```bash
python main.py
```

1. Скрипт запросит ссылку на тайтл MangaLib (например: `https://mangalib.org/ru/manga/otonari-no-tenshi-sama`).
2. Программа спарсит полный список переведенных глав.
3. Введите нужный диапазон в формате `НАЧАЛО-КОНЕЦ` (например: `0-20`) или выберите конкретные главы через запятую (например: `5, 7, 10`).
4. Ссылки на страницы выбранных глав будут собраны последовательно с небольшой паузой между главами.
5. После загрузки выберите: ничего не делать, собрать PDF, собрать CBZ или оптимизировать тома через KCC.
6. Для KCC каждый раз выберите профиль устройства и выходной формат. Результаты появятся в `downloads/<название_манги>/kcc/`.

История последних профилей KCC хранится локально в `.mangalibdownloader.json`. Она влияет только на порядок списка и никогда не выбирает устройство автоматически.

## Возможные проблемы
- **Ошибка 429 (Too Many Requests)**: Программа делает повторные попытки с паузами. Если MangaLib уже временно ограничил запросы, подождите указанное сайтом время и перезапустите загрузку.
- **MOBI через KCC**: Требует установленный Kindle Previewer/KindleGen. EPUB для Kindle работает без него и подходит для Send to Kindle.
